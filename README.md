# peios-go

The independent Go SDK for Peios. Portable codecs use pure Go; native operations require the Peios kernel on Linux/x86-64.

- [Building and testing](docs/building.md)
- [Developer documentation](docs/learn/)
- [Style and review scope](docs/style.md)
- [Historical records](docs/archive/)

Bazel builds and tests the maintained sources and produces development PPK
packages. Go modules and Cargo remain supported for SDK consumers.
